## Descripción
Este repositorio contiene los trabajos prácticos, actividades y proyectos realizados durante la materia Análisis de Sistemas, con el objetivo de aprender y aplicar conceptos relacionados con el análisis, diseño y desarrollo de sistemas informáticos.

## Demo

El repositorio incluye un pequeño demo de una página web con formularios, estilos CSS, JavaScript y una conexión a base de datos MySQL, demostrando conceptos básicos de desarrollo web.

## Requisitos Previos

Para ejecutar el demo se requiere tener instalado lo siguiente:

- Servidor web Apache

- Motor de base de datos MySQL
- PHP (versión compatible con el código)

Se recomienda utilizar un entorno de desarrollo local como XAMPP, WAMP, MAMP o similar, ya que el demo está configurado para ejecutarse en Apache con el usuario `test` y contraseña `user.123$`.
